CPU Process Scheduler & Custom Template Data Structures

Built a discrete-event OS CPU scheduler simulator (schedulesim) in C++17 backed by custom generic containers: ArrayList<T>, LinkedList<T>, BSTMultimap<K,V>, and BSTForwardIterator<K,V>.
